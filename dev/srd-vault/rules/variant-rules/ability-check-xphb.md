# Ability Check
*Source: SRD 5.2 and the Free Rules (2024)* 

An ability check is a [D20 Test](rules/variant-rules/d20-test-xphb.md) that represents using one of the six abilities—or a specific skill associated with an ability—to overcome a challenge.
